# 禁止删除自身运行时

## 触发场景

AI在Hermes会话中执行`rm -rf ~/.hermes/hermes-agent/venv`来"重建venv"。

Hermes进程正运行在此venv的Python中。删除venv→Python解释器找不到模块→API调用全部失败→Hermes崩溃。

## 根因

Hermes使用独立venv（Python 3.11/3.12）运行。系统pip3装到miniconda Python 3.13→包不互通。

**已永久解决：** `hermes-pip`别名指向正确venv。`source ~/.zshrc`后`hermes-pip install xxx`自动装到正确位置。

**不需要重建venv。** 别名方案已经根治了"装错Python"的问题。

## 拦截行为

- 检测到`rm -rf`+`venv`或`删除.*venv`+`重建`等关键词→立即拦截
- 提示用户：用Reasonix或手动终端操作，不要在Hermes会话内执行

## 例外

无。在任何情况下都不应在Hermes会话内删除自身venv。
