# 禁止验证先于结论

**规则层级：元规则。** 这是今天所有错误的上游根因。

**症状（2026-05-29 单次会话4次违反）：**
1. 默认 Obsidian 装了 → 从没 ls 验证过
2. 扫描写死路径 → 假警报 3 个 skill 缺失
3. 说 gstack/guard「不能用」→ 没读代码就下结论
4. 删完才找备份 → 动作排在验证前面

**正确做法：验证永远在动作之前。不确定就查，查到再开口。**
