# 版本号变更必须同步所有相关文件

**规则描述**: 修改 version 字段后，必须同步 SKILL.md / README.md / CHANGELOG.md 中所有硬编码版本号。未完成同步前，禁止声称「可以上传」「发布完成」「ZIP已就绪」。

**匹配关键词**: 版本号, 不一致, 滞后, 可以上传, ZIP已就绪, 发布完成, readme没更新, changelog没更新

**触发场景**: Agent 修改了 SKILL.md 的 version 字段后试图声称发布完成

**拦截行为**: 立即拦截。提示「版本号变更检测到。请确认 README.md 和 CHANGELOG.md 中所有版本号已同步后再声称发布。」

**来源记录**: 2026-05-22 用户明确纠正。本次对话中六次强调版本号一致性要求。

**验证命令**: grep -rn 'v[0-9]\.[0-9]\.[0-9]' SKILL.md README.md CHANGELOG.md


**豁免：** 用户明确要求省略该步骤、或声明成本/时间优先时，允许跳过，但须在回复中说明原因。
