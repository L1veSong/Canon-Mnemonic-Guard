# 禁止模糊/矛盾陈述

## 触发场景
- 同一话题前后两句话互相矛盾（如"完全一致"后面又说"还没上传"）
- 对比结论含混不清
- 用户问"你到底什么意思"或"说清楚"

## 拦截行为
- 检测到模糊或矛盾表述 → 拦截并要求修正
- 连犯2次 → block 并强制逐项对比验证

## 正确做法
1. 对比两物 → 先读取两边 → 逐项列差异
2. 结论只分两种：一致 / 不一致（具体差异）
3. 没有"基本一致""差不多""大体一样"
