# HTML 拆分常见坑点

## 坑1：多余 `<script>` 标签截断外部 JS

**症状：** 页面无交互，`switchPage` 未定义，Console 无报错。

**根因：** `<script>\n<script src="script.js">` ——空 `<script>` 开启内联脚本模式，浏览器把 `src="script.js"` 当作文本内容而非新的脚本标签。

**修复：** 构建 HTML 后 `grep -c '<script'` 必须等于 1。

## 坑2：nav 落入 `display:none` 父容器

**症状：** 底部导航栏消失，但 DOM 里存在。

**根因：** 替换页面内容时 `</div>` 数量不平衡，导致 nav 被关进 `page-budget`（默认 display:none）。

**修复：** 任何内容替换前后必须 `grep` 统计 `<div` 和 `</div>` 数量，差值必须为 0。

## 坑3：内容重复/丢失

**症状：** 美食页 204 家店、景点页出现 3 次。

**根因：** 字符串操作时插入了完整的 HTML 文档副本。

**修复：** 从原始文件重新提取，不用已损坏的文件做二次修改。

## 铁则

1. 改 HTML 前 `cp` 备份
2. 改后立即 `grep` 验证关键标签数量
3. 只在原始文件上做修改，不在已损坏的文件上叠加
4. 拆 CSS/JS 时优先保留单文件版作为回退
