# 地形可视化：2D vs 3D 方案对比

> 2026-06-15 实战结论：新疆互动地图，3D 3次重写均被批"丑"，最终 Canvas 2D 被接受。

## 3D 方案（Three.js 噪音地形）

**实现：**
- Three.js PlaneGeometry + 噪音函数生成地形高度
- HemisphereLight + DirectionalLight 模拟自然光
- 顶点颜色按海拔分级着色
- UnrealBloomPass 后处理发光

**问题：**
- 三角面天然锯齿，SEG=240 仍有明显棱角
- 噪音函数生成的"山脉"不像真实天山
- 光照+阴影无法弥补缺乏纹理的问题
- 用户评价：丑、全是山/没草原/锯齿/不真实

**适用场景：**
- 艺术化/抽象地形（低多边形风格）
- 游戏关卡（配合真实纹理）
- 不需要地理准确性的场景

## 2D 方案（Canvas 逐像素渲染）

**实现：**
- Canvas 2D ImageData 逐像素计算海拔→着色
- 叠加 0.5m 间距等高线
- 同区域检测函数（Yili hover/click）
- CSS 标签叠加

**优势：**
- 完全平滑，无锯齿（像素级渲染）
- 0 外部依赖（不用 Three.js CDN）
- 颜色渐变连续（6 档平滑 blend）
- 等高线增加地形感
- 渲染快，缩放平移流畅

**适用场景：**
- 地形地图/等高线图
- 国家地理杂志风格
- 需要地理区域识别的地图

## 决策树

```
需要真实地形？
├─ 是 → 用 Leaflet + 卫星瓦片（真实数据）
│       需要：OSM/高德瓦片 + GeoJSON 边界
└─ 否 → 需要立体感？
         ├─ 是 → Three.js + 低多边形风格（承认是艺术化）
         └─ 否 → Canvas 2D 逐像素（平滑，干净）
```

## 本次的教训

用户说"要真实的山峦重叠"→ 选了 3D → 3 次迭代都是"丑"→ 转 2D Canvas → 被接受。

关键：用户说的"真实"不是指"3D 立体"，是指"看起来像新疆"。2D 等高线图比 3D 噪音地形更像地图。
