# 国内静态网站托管方案

## 核心问题

Vercel/Netlify/Cloudflare Pages 的默认域名在中国被墙，需要 VPN。GitHub → Vercel 自动部署只能自己看（国外/VPN 环境）。

## ICP 备案关键认知

```
域名 ≠ 服务器。备案管的是「域名指向哪台服务器」。
```

- **域名在哪买不重要**（腾讯云/阿里云/GoDaddy 都行）
- **服务器在哪决定谁能代办备案**（必须同服务商或服务器商代办）
- 腾讯云域名 + Vercel 服务器 → 服务器不在国内 → 备不了案 → 运营商拦截
- 腾讯云域名 + 腾讯云 COS → 同一家 → 备案一条龙

## 国内方案对比（2026.6）

| 方案 | 国内免VPN | 免费 | 免备案 | Git自动部署 |
|------|:--:|:--:|:--:|:--:|
| 腾讯云 COS + 默认域名 | ✅ | ✅ 6月免费 | ✅ | ❌ |
| 腾讯云 COS + 备案域名 | ✅ | ✅ 6月免费 | ❌ 需备案 | ❌ |

| Gitee Pages | ✅ | ✅ | 需实名 | ✅ |
| 阿里云 OSS | ✅ | 40GB 6月 | ✅ (默认域名) | ❌ |

## 推荐组合（用户场景：静态旅游网站）

```
开发流: GitHub → Vercel (自己用 VPN 看)
国内分享: 腾讯云 COS + 备案域名 (女朋友直接打开)
```

### 腾讯云 COS 费用

```
免费额度: 50GB 存储 + 10GB/月流量，有效期 6 个月
6 个月后: ¥0.099/GB/月存储 + ¥0.5/GB 流量
131KB 站点: ~¥0.01/月存储 + ~¥4/月流量 (@1000PV/天)
```

### 备案流程

```
买域名 → 实名认证(1-3天) → 腾讯云 App 提交备案 → 管局审核(7-20天) → 通过
```

关键：域名和服务器必须同一家服务商。腾讯云域名 + 腾讯云 COS = 一条龙。

## 铁则

1. 解释备案时务必区分「域名」和「服务器」——不可让用户误解「域名不能备案」
2. 国内免费托管没有完美方案——要么用默认域名（难记），要么备案（麻烦）
3. 两个部署流并行不冲突：Vercel 自己用 + COS 别人用
